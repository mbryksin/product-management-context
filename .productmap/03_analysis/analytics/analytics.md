# Analytics — Overview

> Phase 3 — Analysis

Analytics work turns raw product data into structured insights about user behaviour, feature performance, and growth levers. It covers experiment design, cohort analysis, and funnel optimisation — the core analytical practices that make product decisions evidence-based rather than intuitive.
